# Entercard Modern Financial Redesign Demo

This project is a modern, premium web application demo for Entercard, redesigned to showcase a sophisticated financial experience. It was built using screens generated via **Stitch** and integrated into a fully functional **React + Vite** application.

## 🌟 Key Features

- **Modern Aesthetic**: A sleek, high-end design featuring glassmorphism, vibrant gradients, and a curated color palette (Entercard Blue).
- **Fully Responsive**: Optimized for various screen sizes using Tailwind CSS.
- **Unified Navigation**: A single-page application (SPA) experience using React Router, connecting 5 distinct redesigned pages:
  - **Start**: Premium landing page with clear value propositions.
  - **Products**: Comparison of credit cards and financial services.
  - **About Us**: Professional history, CSR initiatives, and leadership.
  - **Careers**: Recruitment portal with culture highlights.
  - **Support**: User-friendly help center and FAQ.
- **Global Dark Mode**: A sophisticated dark theme accessible via a global toggle.
- **Interactive Components**: Including a glassmorphism navbar, sticky footer, and cookie consent banner.

## 🛠️ Technology Stack

- **Framework**: [React](https://reactjs.org/) (Version 18)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Navigation**: [React Router DOM](https://reactrouter.com/)
- **Icons**: [Google Material Symbols](https://fonts.google.com/icons) & [Lucide React](https://lucide.dev/)
- **Design Source**: Screens generated and iterated with [Stitch](https://github.com/google/stitch).

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

- [Node.js](https://nodejs.org/) (Version 18 or higher recommended)
- [npm](https://www.npmjs.com/) (usually comes with Node.js)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SwePalm/test-site.git
   cd test-site
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

### Running the Project

To start the development server:

```bash
npm run dev
```

The application will be available at: **`http://localhost:5173/`**

### Building for Production

To create a production-ready bundle:

```bash
npm run build
```

The output will be generated in the `dist/` directory.
